# Next.js portfolio for Asik Syed

This repository now contains a Next.js portfolio that reflects the information from the uploaded CV and public GitHub profile.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Pages
- Home page with hero, about, skills, and projects
- Dedicated projects page

## Customize later
- Replace the profile photo if needed by changing the image URL in `pages/index.js`
- Update email, LinkedIn, or any wording in the portfolio content
- Add more detailed experience sections or a downloadable CV

## Notes
This portfolio is built using public GitHub data and the CV information already shared, and it is ready to be extended or styled further.
